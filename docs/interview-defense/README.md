# Interview Defense Log

One file per session: `YYYY-MM-DD-<theme>.md`. For each question record:

1. The question and the follow-ups you were drilled on (aim for three levels of "why").
2. Your answer shape: assumptions → mechanism → evidence → trade-off → decision.
3. Where you were weak, and the lab or note that closes the gap.
4. Score (1–4) against `docs/readiness-scorecard.md`.

Themes come from Section 10 of the lab document (Interview-Defense Matrix).
